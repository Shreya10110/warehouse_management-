# Warehouse Management System

FastAPI + MongoDB backend and React + Vite frontend, implemented in milestones from the project plan.

## Development

Backend:

```powershell
cd warehouse-backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload
```

Frontend:

```powershell
cd warehouse-frontend
npm install
npm run dev
```
